# Chrono Escrime - Gestionnaire de Temps

Une application web dédiée pour mesuré les temps d'oposition en chorégraphie ASL-FFE

Lien de l'application : [https://viickel.github.io/Chrono_SL.github.io/](https://viickel.github.io/Chrono_SL/)
L'application est compatible pour smartphone et est installable grace au mode PWA (Bouton installer en bas) et peut donc fonctionner hors connexion sur smartphone par exemple.

## 📱 Utilisation

1.  **Lancer le chronomètre :** Utilise le bouton vert (Play/Pause) pour démarrer ou mettre en pause.
2.  **Réinitialiser :** Utilise le bouton rouge pour remettre le compteur à zéro.
3.  **Saisie manuelle :** Clique sur le bouton "Saisie Manuelle" pour ajuster précisément une valeur (format MM:SS:ms).
4.  **Réinitialisation globale :** Le bouton "Réinitialiser Tout" permet de remettre l'ensemble de l'application à zéro d'un seul clic.
